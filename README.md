# Smart Street Light and Car Parking System

## Project Overview

An IoT-based smart-city project that combines automated street lighting with smart parking management.

## Components Used

- Arduino
- ESP32
- IR Sensors
- LEDs
- LCD Display
- Servo Motor

## Features

- Detects vehicles using IR sensors
- Monitors parking-slot availability
- Displays parking status on an LCD
- Automatically controls the parking entrance gate
- Controls street lights based on vehicle detection
- Helps reduce unnecessary energy consumption

## Working

IR sensors detect vehicles and parking-slot occupancy. The microcontroller processes the sensor inputs and displays the available parking information on the LCD. A servo motor controls the entrance gate, while LEDs are used for the smart street-light system.
